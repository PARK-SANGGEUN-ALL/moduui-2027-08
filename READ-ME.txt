■ 들어 있는 것
  index.html         앱 본체
  p/                 지면 이미지 404장 (1800px, 부드러운 계조)
  logo-main.png      로고
  mark.png           심볼 마크 (파비콘)
  og-thumbnail.png   링크 공유용 썸네일

■ GitHub에 올리기
  파일이 409개라 브라우저 드래그 업로드(100개 제한)로는 안 됩니다.
  GitHub Desktop 으로 올려 주세요.

  1. GitHub Desktop 에서 Repository -> Show in Explorer
  2. 열린 저장소 폴더 안의 기존 파일을 전부 삭제
  3. 이 폴더의 내용물을 전부 그 자리에 복사
     (index.html 이 저장소 맨 위에 오도록. 폴더 안에 들어가면 404)
  4. GitHub Desktop 으로 돌아가 -> Commit to main -> Push origin
  5. 1~2분 뒤 접속

  ※ 저장소 맨 위에 index.html 이 바로 보여야 합니다.
     폴더 안에 들어가 있으면 404가 뜹니다.

■ 링크 썸네일 (카톡 · 페북)
  index.html 위쪽 두 줄을 실제 주소로 바꿔 주세요.
    <meta property="og:image" content="https://내주소/og-thumbnail.png">
    <meta property="og:url"   content="https://내주소/">
  카카오톡은 절대주소(https://로 시작)만 인식합니다.

■ 화질에 대해
  원본 PDF 자체가 140dpi 스캔본이라, 무한정 선명해지지는 않습니다.
  다만 이 버전은 글자 가장자리의 부드러운 계조를 그대로 살려서,
  크게 확대해도 계단처럼 깨지지 않습니다.

  용량은 66MB지만 보는 지면만 조금씩 받으므로,
  대학 하나를 여는 데 실제로는 1MB 안팎입니다.

■ 사용법
  · 대학 이름 검색  ->  "경희" 또는 초성 "ㄱㅎ"
  · 오른쪽 아래 ㄱㄴㄷ 막대를 위아래로 쓸면 해당 자음으로 이동
  · 별표를 누르면 즐겨찾기, 다시 열면 "이어 보기"가 뜹니다
  · "맞춤" 을 누르면 145% -> 190% 확대 (손가락 확대도 됩니다)
  · 링크를 누르면 언제나 목록(메인) 화면에서 시작합니다
  · 핸드폰 뒤로가기를 누르면 앱 안에서 이전 화면으로 갑니다
      대학 보는 중 -> 뒤로 -> 이전에 보던 대학 -> 뒤로 -> 목록
      목록에서 한 번 더 누르면 그때 앱이 닫힙니다
